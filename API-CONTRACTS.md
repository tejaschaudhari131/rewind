## Normalization

SAM: submit one noun concept or multiple box/point prompts, never both. Use H.264 MP4 clips
for the recorded motion/teardown and fresh images for stationary checkpoints. The 50-frame
minimum is billed frames, not a capture requirement. `metadata.include_confidence` is the
string `"true"`. Decode the special mask grammar with the documented client/codec; it is
not JSON and the mask payload is base85. Preserve explicit frame indexes and response-scoped
track IDs; frames can be omitted/reordered and an empty result is valid.
Accumulate `response.output_text.delta`; accept evidence only after `response.completed`.
Raw completed output lives in `output[]` message items / `content[]` output_text entries.
The SDK convenience `output_text` is not a raw-response contract.

Glimmer: use a tested vision-capable runtime. The example deliberately omits a guided-decoding
extension because the supported field depends on the pinned runtime. If available, configure
that runtime's documented JSON-schema decoding. In every case validate against
`glimmer-output.schema.json`, check finish status and evidence IDs, and apply a bounded timeout.
Read `choices[0].message.content`; truncation or malformed output gives unknown, not pass.

Wonder: `03-wonder-planner.json` embeds exactly `wonder-output.schema.json`.
Use `text.format` for strict Responses JSON output. Local full contracts use a richer schema
and are not sent to the model. For stateless continuity, replay retained conversation items
and returned reasoning items with encrypted_content intact. Keep explicit workflow state
outside encrypted reasoning. For initial compilation send recorded video/reference images
as well as the evidence ledger; the small planner example represents a subsequent action request.

CUA: the model returns computer_call items. A separate driver executes allowed actions and
returns fresh screenshots as computer_call_output, correlated by call ID. Restrict this lane
to inspection of an already generated CAD artifact. Do not expose policy, calibration files,
arbitrary code execution, acceptance controls or unrelated apps to the driver. This lane is
optional and outside the checkpoint deadline.

Voice: the example uses ENDPOINTING. Wait for sessionId before audio; send raw signed
16-bit little-endian mono PCM at 24 kHz. Only speechComplete issues a command. Partials and
speechEnd do not. PUSH_TO_TALK has different single-turn termination semantics and is not
the configured example. A backend relay owns the provider key.

Image: explanatory cards only. Render cyan targets, red residuals, dimensions and arrows
from recorded evidence or deterministic geometry. Never substitute generated image edits
for ground-truth masks, stress analysis or proof of physical fit.

## Pricing corrections

- Wonder: $4/M input and $20/M output, not the contributor Spark price. No API Contributor mode.
- Spark 1.3 Contributor: $0.10/M input, $0.20/M output; contributor data terms apply.
- SAM: $0.20/1,000 video frames, at least 50 billed per video request ($0.01 minimum);
  $0.0025 per still image. Preserve usage.video_frames_processed.
- Muse Image: $0.01/generated image. Voice: $0.18/audio hour.
- Modal GPU serving and Baseten consumption are separately metered. No cost/latency guarantee
  is inferred from credits or model names.
